# SmartBryte

A responsive, single-page SmartBryte homepage built from the approved homepage specification.

## Scope

- Hero and Introduction to SmartBryte sections only
- Exact approved website copy
- Presentational CTA buttons with no fabricated destinations
- Original decorative SVG artwork; no reference screenshots or stock imagery
- No additional routes, backend, forms, authentication, or operational functionality

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Built with React, TypeScript, Vite, and locally bundled Nunito Sans.
